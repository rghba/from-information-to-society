# From Information to Society | از اطلاعات تا جامعه

یک مجموعه دوزبانه با متن معرفی اصلی، دو پوستر فارسی و انگلیسی و ساختار قسمت‌های آینده.

## انتشار روی GitHub Pages

1. در GitHub، یک مخزن **Public** با نام `from-information-to-society` بسازید و گزینه **Add a README file** را انتخاب نکنید.
2. ZIP آماده را در کامپیوتر **Extract All** کنید؛ ZIP را مستقیماً به GitHub آپلود نکنید.
3. در مخزن، گزینه **uploading an existing file / Add file → Upload files** را بزنید و **محتویات پوشه استخراج‌شده** (از جمله پوشه‌های `assets` و `content`) را بکشید و رها کنید، سپس Commit changes.
4. در **Settings → Pages → Build and deployment** مقدار **Deploy from a branch**، سپس `main` و `/(root)` را انتخاب و Save کنید.
5. نشانی سایت برای این نام کاربری و مخزن: `https://rghba.github.io/from-information-to-society/` خواهد بود، *پس از فعال‌شدن Pages و انتشار موفق*.

**این مخزن و محتوای آن عمومی خواهد بود.** فایل خصوصی، رمز یا اطلاعات محرمانه در آن قرار ندهید.

## معرفی و قسمت‌های بعدی

- معرفی اولیه همیشه در مسیر `#/intro/fa` یا `#/intro/en` باقی می‌ماند.
- فهرست تمام قسمت‌ها در `#/library/fa` و `#/library/en` است.
- اطلاعات قسمت‌ها در `content/catalog.js` تعریف می‌شود؛ محتوای هر قسمت در فایل جدید داخل `content/` قرار می‌گیرد و باید در `index.html` به‌عنوان اسکریپت بارگذاری شود.
- برای قسمت‌های جدید به مخزن فعلی فایل اضافه یا فایل موجود را به‌روزرسانی کنید؛ **مخزن جدید نسازید**. Pages پس از هر Commit روی شاخه main به‌روز می‌شود.
- نشانی هر قسمت `#/episode/<id>/fa` و `#/episode/<id>/en` است، بدون تغییر لینک معرفی.

## یادداشت فنی

این سایت استاتیک است؛ به بک‌اند، دیتابیس یا ساخت پروژه Node نیاز ندارد. فایل `.nojekyll` برای نشر بی‌واسطه فایل‌های سایت در GitHub Pages قرار گرفته است. مسیر تصاویر و CSS نسبی است تا سایت زیر نشانی پروژه نیز کار کند. فونت فارسی به نصب محلی B Nazanin وابسته است و در دستگاه‌هایی که نصب نشده، از فونت جایگزین استفاده می‌شود.

محتوای متن‌ها و فایل‌های اصلی پوستر در تبدیل Netlify به GitHub Pages دست‌نخورده‌اند.
